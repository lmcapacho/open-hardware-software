## 🧩 Description

An open-source VHDL simulator and synthesis frontend used for verification and digital design workflows.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- VHDL-87/93/2008 support for simulation
- CLI-based flow ideal for CI and automation
- Can integrate with GTKWave for waveform viewing
- Supports multiple backends for analysis and execution
- Useful for both learning and professional verification workflows
<!-- FEATURES:END -->
