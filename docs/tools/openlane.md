## 🧩 Description

An open-source RTL-to-GDSII ASIC implementation flow built from tools including OpenROAD, Yosys, Magic, Netgen, and KLayout.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Reference RTL-to-GDSII implementation flow
- Integrates synthesis, timing, routing, DRC, and LVS tools
- Docker and Nix installation options
- Support for open PDK-based ASIC design flows
- Configurable and scriptable design exploration
<!-- FEATURES:END -->
