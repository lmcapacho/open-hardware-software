## 🧩 Description

An autonomous, open-source RTL-to-GDS flow and physical design toolset for digital ASIC implementation.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Integrated digital place-and-route flow
- Timing-driven optimization and analysis
- Automated floorplanning, CTS and routing
- Scriptable flow for research and production
- Active ecosystem with OpenLane integration
<!-- FEATURES:END -->
