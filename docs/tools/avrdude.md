## 🧩 Description

A command-line utility for programming, reading, and configuring AVR microcontrollers through ISP, UPDI, JTAG, and compatible programmers.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Flash, EEPROM, fuse, and lock-bit management
- Support for ISP, UPDI, JTAG, and many programmer adapters
- Compatible with classic and modern AVR devices
- Command-line automation for production workflows
- Official binaries for Windows, Linux, and macOS
<!-- FEATURES:END -->
