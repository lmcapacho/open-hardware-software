## 🧩 Description

A cross-platform ecosystem for embedded development with project management, builds, and device programming.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Unified workflow for multiple MCU platforms
- CLI and IDE integrations including VS Code
- Dependency management for embedded libraries
- Integrated serial monitor and upload tools
- Test and CI support for firmware projects
<!-- FEATURES:END -->
