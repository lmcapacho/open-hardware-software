## 🧩 Description

Open-source finite-element platform for readable Python simulation workflows, AI-agent operation, and reproducible engineering studies. Alpha maturity; requires a compatible FEniCSx/PETSc/MPI runtime.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Editable Python models with materials, loads, solution steps, and verification
- Solid mechanics, heat transfer, modal analysis, and dynamic response workflows
- CLI and AI-agent interfaces for checking, running, and inspecting simulations
- Parameter campaigns, recorded results, and simulation-to-learning workflows
- FEniCSx/DOLFINx, PETSc, and MPI numerical foundation
<!-- FEATURES:END -->
