## 🧩 Description

An open-source RF circuit and electromagnetic simulator with schematic and layout design, DC, S-parameter, harmonic-balance, load-pull, and electrothermal analyses.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Schematic and 2D or 3D layout design
- DC, S-parameter, harmonic-balance, load-pull, and envelope analyses
- Electromagnetic MoM, FEM, FDTD, and thermal FEM capabilities
- Smith charts, Touchstone data, and RF design workflows
- Native installers for Windows, Linux, and macOS
<!-- FEATURES:END -->
