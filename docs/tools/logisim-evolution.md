## 🧩 Description

A cross-platform educational tool for designing, simulating, and analyzing digital logic circuits.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Interactive digital circuit editor and simulator
- Combinational and sequential logic components
- Circuit analysis and truth-table tools
- Timing diagrams and FPGA-oriented features
- Suitable for teaching digital design
<!-- FEATURES:END -->
