## 🧩 Description

A fast open-source SystemVerilog simulator and lint tool that compiles HDL models into C++ or SystemC.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- High-performance compiled simulation
- Linting and static analysis for HDL code
- Generates C++/SystemC models
- Widely used in open-source and industry flows
- Works well with waveform and test frameworks
<!-- FEATURES:END -->
