## 🧩 Description

A debugger and in-system programmer for embedded targets using JTAG and SWD interfaces.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- On-chip debugging via JTAG and SWD
- Flash programming for many MCU families
- Integrates with GDB-based debug workflows
- Scriptable target and interface configuration
- Widely used in open embedded toolchains
<!-- FEATURES:END -->
