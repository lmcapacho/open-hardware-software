## 🧩 Description

A portable, vendor-neutral, timing-driven FPGA place-and-route tool for several open FPGA architectures.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Timing-driven FPGA place and route
- Support for iCE40, ECP5, Nexus, Gowin and other architectures
- Vendor-neutral architecture API
- Interactive graphical user interface
- Integrates with Yosys synthesis flows
<!-- FEATURES:END -->
