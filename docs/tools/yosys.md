## 🧩 Description

An open-source framework for RTL synthesis and formal verification preparation in digital design flows.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- RTL synthesis for Verilog-based designs
- Backends for multiple FPGA and ASIC flows
- Extensible pass-based architecture
- Commonly paired with nextpnr and OpenROAD
- Useful frontend for formal verification pipelines
<!-- FEATURES:END -->
