## 🧩 Description

A front-end for Yosys-based formal verification flows, supporting bounded model checking, induction, and equivalence checking.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Bounded model checking and temporal induction
- Cover and equivalence verification modes
- Configurable SMT and SAT solver backends
- Simple project configuration with SBY files
- Integrates with Yosys and GTKWave
<!-- FEATURES:END -->
