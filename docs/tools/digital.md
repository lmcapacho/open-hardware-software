## 🧩 Description

An educational digital logic designer and event-driven circuit simulator for building, testing, and exporting combinational and sequential circuits.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Interactive design and event-driven simulation of digital logic circuits
- Finite-state machine editor with state tables and circuit generation
- 74xx integrated-circuit library and hierarchical custom components
- Truth-table analysis and combinational or sequential circuit synthesis
- VHDL and Verilog component simulation with external simulators
- Circuit export to SVG, VHDL, and Verilog
<!-- FEATURES:END -->
