## 🧩 Description

A Python-based serial utility for flashing, provisioning, and interacting with Espressif SoCs.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Flash firmware to Espressif SoCs over serial
- Read, erase, and verify flash memory
- Provisioning and security configuration utilities
- Works with ESP32 and related Espressif families
- Cross-platform Python command-line tool
<!-- FEATURES:END -->
