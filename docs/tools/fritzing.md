## 🧩 Description

An open-source electronics design tool for documenting prototypes with breadboard, schematic, and PCB views.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Breadboard view for accessible prototyping
- Schematic and PCB layout views
- Component library for maker hardware
- PCB export for manufacturing workflows
- Cross-platform desktop application
<!-- FEATURES:END -->
