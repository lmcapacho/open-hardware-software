## 🧩 Description

An open-source layout viewer and editor for GDSII and OASIS files, with scripting and verification capabilities for integrated-circuit design.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- View and edit GDSII and OASIS layouts
- Hierarchical layout browsing and layer management
- Ruby and Python scripting APIs
- Built-in DRC and layout manipulation tools
- Cross-platform binary packages
<!-- FEATURES:END -->
