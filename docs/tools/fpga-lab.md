## 🧩 Description

An interactive virtual FPGA laboratory for Verilog and Icestudio designs that connects native Verilator models to a PyQt6 desktop workbench.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Interactive virtual FPGA board and peripheral workbench
- Icestudio project import with Verilog and PCF discovery
- Native Verilator simulation with incremental build caching
- Alhambra II LED, switch, reset, and GPIO mapping
- Reusable virtual peripherals including displays, sensors, and VGA monitors
- English and Spanish user interface
<!-- FEATURES:END -->
