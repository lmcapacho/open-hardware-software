## 🧩 Description

An open-source mixed-level/mixed-signal electronic circuit simulator derived from SPICE3, XSPICE, and Cider. Widely used in education, research, and professional circuit analysis.

---

## 🚀 Key Features

<!-- FEATURES:START -->
- Mixed-level and mixed-signal simulation
- Behavioral modeling with XSPICE
- Device modeling with Cider integration
- Post-processing and plotting capabilities
- Integration with GNUplot, KiCad, and Xschem
- Cross-platform and open-source
<!-- FEATURES:END -->
